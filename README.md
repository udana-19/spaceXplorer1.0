# Space Explorer

A simple text-based space exploration game implemented in Python.

## Description
Space Explorer is an interactive game where players navigate through space, discover planets, manage resources, and make strategic decisions for survival.

## Features
- Space navigation system
- Resource management
- Planet exploration
- Random event encounters
- Ship status monitoring

## How to Play
- Use commands to navigate through space
- Manage your ship's resources
- Explore planets for supplies
- Make strategic decisions to survive
